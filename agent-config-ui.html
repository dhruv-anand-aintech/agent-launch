🚀 Agent Launch Configuration

Configure model and effort level defaults for all agents

How it works

This UI helps you configure environment variables for agent-launch (agl). Each agent can have its own model class (fast/pro), specific model name, and effort level. Changes are exported as shell commands you can run or add to your shell profile.

Export Configuration

Copy these commands and run them in your terminal, or add them to your ~/.bashrc or ~/.zshrc file.
